# 无动物插件

清空生物刷新表，让世界里不生成任何动物。适合纯建筑服、或临时清场做测试。

## 配置文件

位置：`Plugins/无动物插件/NoAnimal.json`

| 项 | 默认 | 说明 |
|---|---|---|
| `Enabled` | `false` | 是否禁用全部动物 |

> ⚠️ **默认 `false`** —— 旧版装上就无条件清空生物表，"装插件 = 全服动物消失"且没有开关、没有提示。本版必须显式设为 `true` 才会生效。

启用与恢复：

```json
{ "Enabled": true }    // 禁用：世界不再生成任何动物
{ "Enabled": false }   // 恢复：回到原生生物刷新表
```

改完**重启服务器**生效（`Load()` 在世界载入时读配置）。生效时服务端日志会打：

```
[无动物] 已清空生物刷新表（原 87 种生物不再生成）。如需恢复：把 NoAnimal.json 的 Enabled 设为 false 并重启服务器。
```

## ⚠️ 与「动物生成条件修改」互斥（重要）

两者共用 `ICreatureSpawnEventHandle.InitCreatureTypes` 这个钩子，**都调用 `creatureTypes.Clear()`**。

核心是 `foreach` 遍历 + 短路：**谁后执行谁生效**。若本插件后执行，会把「动物生成条件修改」精心配置的整张生物表（含 60+ 种自定义刷新规则）清成空。

**两者只能二选一。** 本插件的定位是"全清"，对方是"自定义表"，功能上完全冲突。

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| 插件名 | `"无动物测试"`（作者自标实验品） | `"无动物插件"` |
| 开关 | 无，初始化即清空 | 配置驱动，默认关闭 |
| 状态可见性 | 无 | 每次生效打日志，说明如何恢复 |

## 注意事项

- **不会清除世界里已有的生物**，只是不再刷新新的。想立刻清场请配合「清理插件」。
- 玩家用指令刷出的生物（若核心支持）不受影响。
- 这是一个**功能性开关**，不是安全防护。
