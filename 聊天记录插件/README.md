# 聊天记录插件

把全服公共/队伍频道聊天落盘，便于事后追溯。

> ⚠️ **默认不记录私聊**。私聊属隐私内容，`RecordPrivateChat` 默认 `false`，需要时显式打开。

## 配置文件

位置：`Plugins/聊天记录插件/ChatRecord.json`

| 项 | 默认 | 说明 |
|---|---|---|
| `RecordPublicChat` | `true` | 记录公共频道 |
| `RecordTeamChat` | `true` | 记录队伍频道 |
| `RecordPrivateChat` | `false` | 记录**私聊**（隐私内容，默认关） |
| `RecordCommands` | `false` | 记录 `/` 开头的命令 |
| `MaxFileBytes` | `8388608`（8 MB） | 单个日志文件上限，超出后当日不再追加 |
| `KeepDays` | `30` | 日志保留天数，超期文件自动删除 |
| `AnnounceRetention` | `true` | 启动时在日志里说明记录范围 |

## 日志输出

按天分文件：`Plugins/聊天记录插件/ChatRecord-YYYY-MM-DD.txt`

格式为制表符分隔：

```
2026-10-04 20:15:33	[公]	张三(12345678)	大家好啊
2026-10-04 20:15:40	[队]	李四(87654321)	集合打怪
```

- 时间用 **24 小时制**（旧版用 `hh` 是 12 小时制且不区分 AM/PM，跨中午会错乱）
- 频道标记：`[公]` 公共 / `[队]` 队伍 / `[私]` 私聊
- 昵称与社区 ID 都记，换名后仍可追溯

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| 私聊 | ⚠️ **私聊被明文落盘** | 默认不记录 |
| `External` 标志 | ⚠️ 正常消息置 `true` —— 在核心的 `foreach` 里会**改变全服聊天处理流程** | 显式置 `false`，原样放行 |
| 文件增长 | 无限增长、无轮转 | 按天分文件 + 单文件上限 + 超期删除 |
| 时间格式 | `hh:mm:ss`（12 小时制） | `HH:mm:ss`（24 小时制） |

> ⚠️ **`External` 的语义**：置 `true` 表示"这条消息由外部插件接管"，核心会改变后续处理。旧版对**正常聊天**置 `true` 是个隐患——它可能让主城的聊天拦截、告示牌广播等插件失效。本版始终置 `false`。

## 注意事项

- **日志含玩家身份信息**，文件属敏感文件，注意访问权限。
- 去重只比对"上一条"——核心若隔几条重复派发同一条消息仍会重复记录。
- 写入失败只打日志，**绝不会影响聊天本身**。
- 想更全面的行为审计（含方块操作、交互等），本仓库的「玩家操作日志插件」是更好的选择。
