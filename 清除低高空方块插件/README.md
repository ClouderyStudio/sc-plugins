# 清除低高空方块插件

禁止玩家改动基岩层与世界顶层的方块，防止破坏世界边界或在空中无限搭高。

## 配置文件

位置：`Plugins/清除低高空方块插件/ClearLowLevel.json`

| 项 | 默认 | 说明 |
|---|---|---|
| `MinY` | `5` | 低于（含）此高度不可改。`0` = 不限制下界 |
| `MaxY` | `250` | 高于（含）此高度不可改。`0` = 不限制上界 |
| `AllowServerManager` | `true` | 是否放行管理员 |
| `NotifyPlayer` | `true` | 拦截时是否给玩家屏幕提示 |

## 关于默认值

`MaxY = 250` 沿用旧版数值。**不同版本的世界高度上限可能不同**，请按自己服务器的实际高度调整；不确定就先设成 `0`（不限制上界），只保留下界。

## 拦截时的行为

- 玩家会看到「你不能在这个高度建造（Y=xx ...）」
- 服务端日志记一行：`[清除低高空方块] 已拦截 [社区ID]名字 在 (x,y,z) 改方块（...）`

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| 高度阈值 | 硬编码 `5` / `250` | 配置可配，`0` = 不限制 |
| 管理员 | 无豁免，管理员也拦 | `AllowServerManager` 控制 |
| 拦截反馈 | 静默失败，玩家不知道为什么点不动 | 屏幕提示 + 服务端日志 |

## 注意事项

- **管理员豁免默认开着**。关掉它的话，`/place`、领地插件的批量放置都会被一起拦掉。
- 这只拦**玩家改方块**（`IBlockChangeEventHandle`），不阻止插件自身或世界生成器写入方块。
