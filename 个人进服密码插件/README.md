# 个人进服密码插件

为每个玩家分配独立的"房间密码"，**密码 + 昵称双匹配**才放行进服。适合开服主测试、防止外人进自己的服。

## 命令

| 命令 | 权限 | 说明 |
|---|---|---|
| `/setpc add <名字> <密码>` | AuthLevel 1000 | 给某玩家设置密码 |
| `/setpc rem <名字>` | AuthLevel 1000 | 移除某玩家的密码（之后该玩家可直接进服） |
| `/setpc show [名字]` | AuthLevel 1000 | 列出已设密码的玩家 |

> ⚠️ 与「白名单插件」共用 `BanEventManager.IsBan` 同一个钩子，核心是 `foreach` 遍历、**任一返回 true 即拒绝**。两个准入插件同时启用会互相干扰，**只能二选一**。

## 密码显示规则

`show` **一律打码**，只显示首尾各 1 个字符：

```
已设置密码的玩家（2 人，密码已打码）:
  张三 -> a****9
  李四 -> ***
```

> ⚠️ 旧版的 `/setpc show` 会把**所有玩家的密码明文**打印到聊天/日志——一条命令泄露全服密码。本版已修掉。

## 配置文件

位置：`Plugins/个人进服密码插件/PersonalCode.json`

```json
{
  "|张三": "abc123",
  "|李四": "secret"
}
```

key 格式为 `社区ID|昵称`（当前用 `|昵称` 形式，社区 ID 为空）。首次给某人设密码时会按其社区 ID 写入。配置文件损坏时会保留原数据并报警，不会清空。

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| `/setpc show` | ⚠️ **明文打印全部密码** | 全部打码 |
| JSON 损坏 | null 覆盖字典，之后查询必崩 | 保留原数据 + 报警 |
| 主键 | 仅昵称（改名即失效） | 社区ID + 昵称 |
| 配置写入 | 直接覆写 | 原子写入 |

> ⚠️ **拒绝连接的实现变了**：`ConnectionRejectPackage` 在新版核心里是**内部类**（无 `public` 修饰符），插件拿不到它，无法像旧版那样自己发拒绝包。现在改为返回 `true` 交由核心按标准流程拒绝，提示文案由核心决定（插件自定义的拒绝理由无法送达玩家）。

## 注意事项

- 密码是**明文存盘**的。配置文件属敏感文件，不要放进公开可访问的目录。
- 没给某人设密码 → 不会被拦。
- `IsBanIp` 恒返回 false：本插件只管账号准入，不封 IP。
