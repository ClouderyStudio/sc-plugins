# 火柴记录插件

记录玩家点燃火焰的行为，用于事后追溯。

> ⚠️ **注意命名**：插件名叫"火柴记录"，但监听的是 `IFireEventHandle`——这是**点燃火焰**事件（火把、打火机点燃），不是玩家手里那根火柴物品。名字沿用旧版以保持兼容。

## 配置文件

位置：`Plugins/火柴记录插件/MatchRecord.json`

| 项 | 默认 | 说明 |
|---|---|---|
| `LogFire` | `false` | 记录"朝一个方向点火"（含坐标与方向，高频） |
| `LogFireTerrain` | `true` | 记录"点燃某个格子的方块"（低频） |
| `LogFireGeneration` | `false` | 记录火焰蔓延（每帧可能调用多次） |
| `IncludePlayerName` | `true` | 日志里是否带玩家昵称（昵称属个人信息） |
| `FireGenerationLogInterval` | `30` | 蔓延日志的最小间隔（秒），防止刷屏 |
| `BlockFire` | `false` | 是否**阻止**点火。默认只记录不阻止 |

输出进服务端日志，形如：

```
[火柴记录] [12345678]张三 点燃了 (10,64,-20) 的方块
```

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| 接口实现 | 只实现 2/3 个方法 | 补上 `OnFireGeneration`（新版接口新增，漏掉会编译失败） |
| 日志量 | 无条件全记录，日志量随火把使用暴涨 | 全部可配，默认只记低频那一项 |
| 隐私 | 直接输出昵称 + 精确坐标 | 昵称可关 |
| 阻止能力 | 无 | `BlockFire` 可开 |

> ⚠️ `OnFireGeneration` 是**火焰蔓延**判定，返回 `false` 可以阻止这一格起火。旧版没实现它，意味着火焰蔓延完全不受控——本版默认放行（与旧版行为一致），需要管控时开 `BlockFire`。

## 注意事项

- 这只是**记录**，不阻止任何行为（除非开 `BlockFire`）。
- 想审计玩家行为，本仓库的「玩家操作日志插件」是更全面的方案；这个只管点火。
