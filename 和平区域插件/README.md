# 和平区域插件

指定区域内禁止玩家互相伤害，攻击者会受到轻微反噬。

## 功能

- 配置若干立方体区域，区域内玩家之间互相攻击会被拦下
- 攻击者受到 `0.1` 点反噬伤害（文案「和平区域」）
- **攻击者或受害者任一方在区域内就禁战**——避免"站在区内打区外的人"

## 配置文件

位置：`Plugins/和平区域插件/PeaceAreas.json`

```json
[
  {
    "MinX": -100, "MinY": 0, "MinZ": -100,
    "MaxX":  100, "MaxY": 256, "MaxZ": 100
  }
]
```

坐标写反了也能正常工作——插件每次判断前会自动归一化 Min/Max。

| 项 | 说明 |
|---|---|
| `MinX/MinY/MinZ` | 区域最小角 |
| `MaxX/MaxY/MaxZ` | 区域最大角 |

文件不存在时插件正常运行，但不会有任何保护区域（空列表）。

## 与旧版的差异

| 项 | 旧版 | 本版 |
|---|---|---|
| 伤害调用 | `Injure(a, b, true)` 3 参 | `Injure(a, b, true, cause)` **4 参** |
| 反噬文案 | `"天惩！"`（从别的插件复制） | `"和平区域"` |
| 判定范围 | 只看攻击者位置 | 攻击者或受害者任一在内 |
| 坐标归一化 | 依赖 `SubsystemGameInfo` 非空，首次进档会被跳过 | 每次判断前归一化 |
| 配置写入 | 直接覆写 | 原子写入（`.partial` → 复制） |

> ⚠️ **重要**：`ComponentHealth` 在新版**只有 4 参的 `Injure`**。3 参版本属于 `ComponentCreatureHealth`，直接调会编译失败。若你从别处移植代码遇到 `CS1501`，就是这个问题。

## 互斥说明

与「个人领地与玩家传送插件」的领地保护概念相近但不冲突：领地是"谁的区域"，和平区域是"禁战区"，两者可叠加。

## 注意事项

- 反噬伤害会触发 `ICreatureHealthEventHandle`，如果你另有伤害类插件，注意别形成互相调用
- 区域判定是**方块坐标**（整数），玩家坐标落在区域内即生效
